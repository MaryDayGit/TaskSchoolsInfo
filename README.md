# ІнфоКлас

Веб-платформа для уроков информатики во 2–9 классах (НУШ). Интерфейс на украинском, работает на ПК и телефонах, подходит и для офлайн-, и для онлайн-уроков.

## Что уже умеет

**Учитель**

- Классы с 6-значным кодом, список учеников (можно вставить столбцом из таблицы).
- Карточки входа для печати: код класса и пароль каждого ученика.
- Конструктор тестов: один правильный вариант, несколько вариантов, ответ словом или числом. 5 готовых шаблонов по темам НУШ.
- Домашние задания со сроком сдачи, количеством попыток и показом правильных ответов. Ссылку можно отправить в **Google Classroom** одной кнопкой.
- **Живая игра** в стиле Kahoot: экран для проектора, ученики отвечают с телефонов или ПК, из класса или из дома.
- Результаты по каждому вопросу (видно, какие вопросы оказались самыми сложными) и **журнал класса** с выгрузкой в Excel / Google Таблицы.

**Ученик**

- Вход без почты: код класса → своё имя → пароль.
  - 2–4 класс: пароль из **3 картинок** 🐱⭐🚀.
  - 5–9 класс: простое слово с цифрами (`ракета47`).
- Задания по одному вопросу на экран, черновик сохраняется при случайном обновлении страницы.
- Для младших: крупные кнопки, **озвучка вопросов** 🔊, мягкие формулировки, в живой игре нет рейтинга и гонки на скорость (формирующее оценивание).

## Технологии

| Часть       | Стек                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| Фронтенд    | React 19, React Router, TanStack Query, Vite                           |
| Бэкенд      | Node.js 22, Fastify 5, Socket.IO (живые игры)                          |
| База данных | PostgreSQL + Drizzle ORM (миграции в `apps/server/drizzle`)            |
| Общий код   | `packages/shared`: схемы вопросов (Zod), проверка ответов, типы API    |
| Тесты       | Vitest; сервер тестируется на встроенном Postgres (PGlite), без Docker |

```
apps/
  server/   API, авторизация, движок живых игр
  web/      интерфейс учителя и ученика
packages/
  shared/   общие типы, схемы и логика проверки ответов
docs/       развёртывание и план развития
```

## Локальный запуск

Нужны Node.js 22+ и PostgreSQL (или Docker).

```bash
npm install
cp .env.example .env          # при необходимости поправьте DATABASE_URL
# Postgres через Docker, если нет своего:
docker run -d --name infoklas-db -p 5432:5432 \
  -e POSTGRES_USER=infoklas -e POSTGRES_PASSWORD=infoklas -e POSTGRES_DB=infoklas postgres:16-alpine
npm run dev                   # сервер :3000 + интерфейс http://localhost:5173
```

Миграции базы применяются автоматически при старте сервера. Первый пользователь, открывший «Я вчитель», может зарегистрироваться. После этого регистрация закрыта (см. `TEACHER_SIGNUP`).

## Команды

| Команда               | Что делает                                                    |
| --------------------- | ------------------------------------------------------------- |
| `npm run dev`         | режим разработки с автоперезагрузкой                          |
| `npm test`            | все тесты                                                     |
| `npm run check`       | линтер + форматирование + типы + тесты (то же, что в CI)      |
| `npm run build`       | продакшен-сборка                                              |
| `npm start`           | запуск собранного сервера                                     |
| `npm run db:generate` | новая миграция после изменения `apps/server/src/db/schema.ts` |

## Безопасность и данные детей

- У детей не собираются email и телефоны. Хранятся только имя в выбранном учителем виде (рекомендуем «Имя + первая буква фамилии») и выданный учителем пароль.
- Пароли учителей хешируются (scrypt). Пароли учеников выдаёт учитель, и они хранятся так, чтобы карточки можно было распечатать повторно. Ребёнок не придумывает их сам, поэтому они не могут совпасть с его паролями на других сайтах.
- После 5 неверных попыток вход ученика блокируется на минуту: картинку-пароль нельзя подобрать перебором.
- Сессии хранятся в httpOnly-cookie. Учитель видит только свои классы, ученик только задания своего класса.
