# Руководство учителя

Здесь описана повседневная работа с ІнфоКлас: как завести класс, подготовить тест, выдать домашнее задание, провести живую игру и посмотреть результаты.

> Интерфейс сервиса на украинском. В этом руководстве названия кнопок приводятся так, как они написаны на экране, например **«Дати завдання»**.

## 1. Первый вход

1. Откройте адрес сервиса и нажмите **«Я вчитель»**.
2. При самом первом входе появится ссылка **«Зареєструватися»**. Укажите имя и отчество (так вас увидят ученики), почту и пароль не короче 8 символов.
3. После регистрации первого учителя регистрация автоматически закрывается: больше никто не сможет создать учительский аккаунт. Как открыть её для коллег, описано в [DEPLOY.md](DEPLOY.md#переменные-окружения) (переменная `TEACHER_SIGNUP`).

Вход сохраняется на 30 дней. На общем школьном компьютере нажимайте **«Вийти»** в правом верхнем углу.

## 2. Классы

**Создать класс:** **«Мої класи» → «+ Новий клас»**, укажите название (например, `5-А`) и год обучения.

От года обучения зависит режим:

| Год обучения                | Вход ученика                         | Живая игра                            |
| --------------------------- | ------------------------------------ | ------------------------------------- |
| 2–4 класс (начальная школа) | 3 картинки                           | без рейтинга и без бонуса за скорость |
| 5–9 класс                   | слово с цифрами, например `ракета47` | рейтинг топ-5 и бонус за скорость     |

У каждого класса есть **код из 6 цифр**. Он крупно показан на странице класса, и с ним ученики входят в сервис.

**Настройки класса** (кнопка **«⚙ Налаштування»**):

- изменить название и год обучения;
- **«Новий код класу»**: если код попал к посторонним. Старый сразу перестаёт работать, уже вошедшие ученики остаются в системе;
- **«Видалити клас»**: удаляет класс вместе с учениками и всеми результатами. Отменить нельзя.

> Перевели класс из 4-го в 5-й? Поменяйте год обучения в настройках и выдайте ученикам новые пароли (см. ниже): картинки заменятся словами.

## 3. Ученики и карточки входа

### Добавление учеников

Вкладка **«Учні»** → поле **«Додати учнів»**. Пишите каждое имя с новой строки. Можно вставить столбец из Excel или Google Таблиц.

Советы:

- пишите имя и первую букву фамилии: `Оля К.`, `Петро М.`. Этого достаточно, чтобы ребёнок нашёл себя в списке, и при этом не хранится лишних персональных данных;
- в одном классе не может быть двух одинаковых имён: сервис подскажет, если такое имя уже есть;
- в одном классе может быть до 60 учеников.

Пароль каждому ученику сервис придумывает сам. Посмотреть пароли можно, отметив **«Показати паролі»**.

### Карточки входа

Кнопка **«🖨 Картки входу»** открывает страницу для печати. На каждой карточке есть адрес сайта, код класса, имя ученика и его картинки или пароль. Распечатайте, разрежьте и раздайте. Для онлайн-урока можно сделать скриншот карточки и отправить каждому ученику лично.

### Если ученик забыл пароль или потерял карточку

- **«Новий пароль»** напротив имени: старый пароль перестаёт работать, появляется новый (сразу видно в таблице).
- Если ученик 5 раз подряд ошибся с паролем, вход для него блокируется на **1 минуту**. Это защита от подбора. Подождите минуту или выдайте новый пароль: он сразу снимает блокировку.

### Другие действия

- **«Змінити»**: исправить имя.
- **«Видалити»**: удалить ученика вместе со всеми его результатами. Его вход перестанет работать даже на устройствах, где он уже был в системе.

## 4. Тесты

Раздел **«Тести»** в верхнем меню. Один тест можно многократно использовать для разных классов, и как домашнее задание, и как живую игру.

### Шаблоны

Внизу страницы есть готовые шаблоны по темам НУШ:

| Шаблон                         | Для каких классов |
| ------------------------------ | ----------------- |
| Комп'ютер і його пристрої      | 2–4               |
| Безпечний інтернет             | 2–6               |
| Одиниці вимірювання інформації | 5–7               |
| Алгоритми та виконавці         | 5–7               |
| Python: перші кроки            | 8–9               |

**«Використати»** создаёт вашу копию шаблона, её можно свободно менять.

### Типы вопросов

| Тип                              | Как отвечает ученик          | Как проверяется                                                                                                       |
| -------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Одна правильна відповідь**     | выбирает один вариант        | совпал ли вариант                                                                                                     |
| **Кілька правильних відповідей** | отмечает несколько вариантов | засчитывается, только если отмечены **все** правильные и **ни одного** лишнего                                        |
| **Відповідь словом або числом**  | пишет ответ                  | сравнивается со списком правильных ответов; регистр, лишние пробелы и разные апострофы (`'`, `’`, `ʼ`) не учитываются |

Для вопросов с ответом словом добавляйте разные варианты написания через **«+ Ще варіант написання»**, например `мишка`, `миша`, `комп'ютерна мишка`.

### Редактор

- В вопросе может быть от 2 до 8 вариантов. Правильный вариант отмечается кнопкой **✓** справа.
- Пустые варианты при сохранении убираются автоматически.
- **⏱** задаёт время на ответ в **живой игре**, от 10 секунд до 3 минут. На домашние задания это не влияет.
- **↑ ↓** меняют порядок вопросов, **«Копія»** дублирует вопрос.
- Чтобы в тексте вопроса был код, просто переносите строки: отступы и переносы сохраняются.
- В тесте может быть до 50 вопросов.
- Если вы уходите со страницы с несохранёнными изменениями, сервис переспросит.

> Изменение теста **не меняет** уже выданных заданий: в каждое задание сохраняется копия теста на момент выдачи. Поэтому результаты учеников никогда не «поедут».

## 5. Домашние задания

На странице класса: **«📝 Дати завдання»**.

| Настройка                          | Что значит                                                                                                                       |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Тест**                           | какой тест выдать                                                                                                                |
| **Виконати до**                    | крайний срок. После него ответы не принимаются. Можно не указывать                                                               |
| **Кількість спроб**                | 1, 2, 3 или без ограничений. В журнал идёт **лучшая** попытка                                                                    |
| **Показувати правильні відповіді** | после сдачи ученик увидит правильные ответы на вопросы, где ошибся. Если выключить, он увидит только, какие вопросы решены верно |

После выдачи задание сразу появляется у учеников в кабинете в разделе **«Треба зробити»**.

**Как ученик выполняет задание:** вопросы идут по одному на экран, есть кнопки «Назад» и «Далі». В конце показывается, на сколько вопросов он ответил, и нужно подтвердить отправку. Ответы сохраняются в браузере, поэтому при случайном обновлении страницы ничего не теряется. После отправки ученик видит результат и разбор.

**Изменить срок** или **закрыть задание досрочно**: откройте результаты задания → **«Змінити термін»** → **«Закрити зараз»** либо новая дата.

## 6. Google Classroom

У каждого задания есть две кнопки:

- **«Поділитися в Classroom»**: открывает Google Classroom с уже прикреплённой ссылкой. Выберите курс и тип публикации (задание или объявление), затем опубликуйте;
- **«🔗 Копіювати посилання»**: ссылку можно отправить в любой мессенджер.

Ссылка ведёт ученика сразу на вход в **нужный класс**, а после входа прямо на это задание.

> Сейчас оценки в Classroom не переносятся автоматически. Для этого есть выгрузка журнала в таблицу (раздел 8). Полная интеграция с Classroom API есть в [плане развития](ROADMAP.md).

## 7. Живая игра на уроке

Это викторина в реальном времени, как в Kahoot: вопрос на проекторе, ученики отвечают со своих устройств.

### Как провести

1. На странице класса нажмите **«🎮 Жива гра»**, выберите тест и нажмите **«▶ Почати»**.
2. Откроется экран игры. Выведите его на проектор и нажмите **«⛶ На весь екран»**.
3. На экране показаны адрес сайта и **код класса**. Ученики входят в свой кабинет (или уже в нём) и видят баннер **«Почалась гра! → Приєднатися»**.
4. Имена присоединившихся появляются на экране. Когда все подключились, нажмите **«▶ Почати гру»**.
5. Для каждого вопроса:
   - идёт таймер, внизу видно, сколько учеников уже ответили;
   - когда ответили все или вышло время, правильный ответ показывается автоматически. Показать его раньше можно кнопкой **«Показати відповідь»**;
   - на экране видно, сколько человек выбрали каждый вариант (для вопросов со словом показаны все ответы);
   - **«Наступне питання →»** открывает следующий вопрос.
6. После последнего вопроса нажмите **«Підсумки 🏁»**. Результаты автоматически сохраняются в журнал класса.

**«Завершити»** в правом верхнем углу заканчивает игру досрочно. В журнал идут только те вопросы, которые успели прозвучать. Если игру завершить до первого вопроса, в журнал ничего не попадёт.

### Онлайн-урок

Всё работает так же: покажите экран игры через демонстрацию экрана в Meet или Zoom, а ученики заходят в свой кабинет из дома.

### Баллы (5–9 класс)

За правильный ответ ученик получает от 500 до 1000 баллов: чем быстрее ответ, тем больше баллов. После каждого вопроса показывается топ-5. В журнал идёт **процент правильных ответов**, а не баллы.

### Особенности

- Ученик может присоединиться уже во время игры. Если у него на минуту пропал интернет, телефон переподключится сам.
- Одновременно в классе может идти только одна игра: новая завершает предыдущую, и её результаты сохраняются.
- Незавершённая игра без активности автоматически закрывается через 3 часа.

## 8. Результаты и журнал

### Результаты задания

Откройте задание на вкладке **«Завдання»** → **«Результати»**:

- по каждому ученику: процент, число попыток и цветные точки по каждому вопросу (🟢 верно, 🔴 неверно, серая — не сдано);
- ниже статистика по вопросам: какой процент класса ответил верно. Так видно, какие темы стоит повторить.

Страница обновляется сама каждые 15 секунд, поэтому её удобно держать открытой, пока класс выполняет задание.

### Журнал класса

Вкладка **«Журнал»**: таблица «ученики × работы» (📝 домашние задания, 🎮 живые игры). В каждой клетке процент правильных ответов в лучшей попытке. Цвета:

| Цвет       | Процент      |
| ---------- | ------------ |
| 🟢 зелёный | 75% и больше |
| 🟡 жёлтый  | 50–74%       |
| 🔴 красный | меньше 50%   |

**«⬇ Завантажити для Excel / Google Таблиць»** скачивает CSV-файл. Excel откроет его сразу. В Google Таблицах: **Файл → Импорт → Загрузка**, разделитель **«точка с запятой»**.

> Процент — это не оценка. Какую оценку поставить (и ставить ли её, если оценивание формирующее), решает учитель.

## 9. Младшие и старшие классы: в чём разница

|                     | 2–4 класс                                        | 5–9 класс                        |
| ------------------- | ------------------------------------------------ | -------------------------------- |
| Вход                | 3 картинки из 12                                 | слово с цифрами                  |
| Интерфейс           | крупнее шрифт и кнопки                           | обычный                          |
| Озвучка вопросов 🔊 | есть (голос браузера, украинский)                | нет                              |
| Живая игра          | без рейтинга, каждый правильный ответ 100 баллов | рейтинг топ-5, бонус за скорость |
| Сообщения           | мягкие («Гарна спроба! Далі буде ще краще!»)     | нейтральные                      |

## 10. Частые вопросы

**Ученик не видит своего имени в списке.** Проверьте, что он ввёл код именно своего класса и что вы добавили его на вкладке «Учні».

**«Забагато спроб. Зачекай хвилинку»** — ученик 5 раз ошибся с паролем. Подождите минуту или нажмите «Новий пароль».

**Ученик перешёл в другой класс.** Удалите его из старого класса и добавьте в новый. Результаты из старого класса при этом удалятся, поэтому при необходимости сначала выгрузите журнал.

**Можно ли выдать одно задание нескольким классам?** Да: выдайте один и тот же тест в каждом классе отдельно.

**Сайт долго открывается утром.** На бесплатном хостинге сервер «засыпает» без запросов. Откройте сайт за пару минут до урока (подробнее в [DEPLOY.md](DEPLOY.md)).

**Работает ли на старых телефонах?** Нужен современный браузер (Chrome, Safari, Firefox, Samsung Internet последних лет). Приложение устанавливать не нужно. По желанию сайт можно добавить на главный экран: «Добавить на главный экран» в меню браузера.

**Где хранятся данные?** В базе данных PostgreSQL, которую вы подключили при развёртывании. Какие данные хранятся, описано в [ARCHITECTURE.md](ARCHITECTURE.md#безопасность-и-персональные-данные).
