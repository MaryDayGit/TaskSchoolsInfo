# План развития

## ✅ Этап 1. Основа (готово)

- Кабинет учителя, классы, ученики, вход по коду класса и картинкам или паролю, карточки входа.
- Конструктор тестов и шаблоны по темам НУШ.
- Домашние задания, результаты, журнал, экспорт CSV, ссылки для Google Classroom.
- Живые игры (викторины) для урока и онлайн-урока.

## Этап 2. «Робот на поле» (2–6 класс)

Линия «Алгоритмы» для младших классов. Ученик составляет из стрелок программу, по которой робот доходит до цели. Уровни усложняются: последовательность шагов → «повтори N раз» → «если перед роботом стена».

- Управление пальцем на телефоне, перетаскивание блоков на ПК.
- Уровни можно давать как домашнее задание (результат попадает в журнал).
- Редактор уровней для учителя.

## Этап 3. Python-тренажёр (7–9 класс)

- Код выполняется прямо в браузере (Pyodide), без нагрузки на сервер.
- Задачи с автоматической проверкой на тестах, подсказки, пошаговое выполнение.
- Банк задач по программе, в том числе для подготовки к ДПА.

## Этап 4. Модули «Информация и данные» (4–8 класс)

- Двоичная система: «включи лампочки-биты», дуэли на скорость перевода.
- Шифры (Цезарь, Морзе): командная игра «зашифруй — расшифруй».
- Пиксельные рисунки по координатам (как компьютер кодирует изображение).
- Квест по цифровой безопасности.

## Дальнейшие улучшения

- Картинки в вопросах теста.
- Полноценная интеграция с Google Classroom API: автоматическое создание заданий и выгрузка оценок.
- Работа без сети (PWA с офлайн-кэшем) для слабого школьного Wi‑Fi.
- Несколько учителей в одной школе, общий банк тестов.
