# Развёртывание

## Вариант 1. Бесплатно: Render + Neon (рекомендуется для старта)

| Сервис                       | Что даёт                          | Ограничение бесплатного тарифа                                                |
| ---------------------------- | --------------------------------- | ----------------------------------------------------------------------------- |
| [Neon](https://neon.tech)    | PostgreSQL                        | 0,5 ГБ: хватит на тысячи учеников и лет результатов                           |
| [Render](https://render.com) | запуск приложения по `Dockerfile` | «засыпает» после 15 минут без запросов, первое открытие занимает около минуты |

> Про «засыпание»: откройте сайт за 1–2 минуты до урока, и дальше он работает без задержек. Если это станет мешать, переходите на платный тариф Render (около $7/мес) или на вариант 2. Код менять не придётся.

### Шаг 1. База данных в Neon

1. Зарегистрируйтесь на neon.tech и создайте проект (регион: Frankfurt, ближе всего к Украине).
2. Скопируйте **Connection string**. Она выглядит как `postgresql://user:pass@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`.

### Шаг 2. Приложение в Render

1. Зарегистрируйтесь на render.com через GitHub.
2. **New → Blueprint** → выберите этот репозиторий. Render прочитает `render.yaml`.
3. В поле `DATABASE_URL` вставьте строку из Neon. `JWT_SECRET` сгенерируется автоматически.
4. Нажмите **Apply**. Через несколько минут сайт будет доступен по адресу вида `https://infoklas.onrender.com`.
5. Откройте сайт → «Я вчитель» → зарегистрируйтесь. Первый учитель регистрируется свободно, после этого регистрация закрывается.

Каждый push в основную ветку автоматически обновляет сайт. Миграции базы применяются сами при запуске.

### Свой домен (по желанию)

В Render: Settings → Custom Domains. HTTPS настраивается автоматически.

## Вариант 2. Свой сервер с Docker

Подойдёт любой VPS (например, бесплатная виртуальная машина Oracle Cloud Always Free или VPS примерно за 5 €/мес).

```bash
git clone <репозиторий> && cd TaskSchoolsInfo
cat > .env <<EOF
JWT_SECRET=$(node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))")
POSTGRES_PASSWORD=придумайте-надёжный-пароль
TRUST_PROXY=true
EOF
docker compose up -d --build
```

Приложение слушает порт 3000. Для HTTPS поставьте перед ним [Caddy](https://caddyserver.com), он сам получает сертификат:

```
# /etc/caddy/Caddyfile
infoklas.example.com {
    reverse_proxy localhost:3000
}
```

Резервная копия базы:

```bash
docker compose exec db pg_dump -U infoklas infoklas > backup-$(date +%F).sql
```

## Переменные окружения

| Переменная       | Обязательна | Описание                                                            |
| ---------------- | ----------- | ------------------------------------------------------------------- |
| `DATABASE_URL`   | да          | строка подключения к PostgreSQL                                     |
| `JWT_SECRET`     | да          | случайная строка ≥ 32 символов для подписи входа                    |
| `TEACHER_SIGNUP` | нет         | `true`, чтобы после первого учителя могли регистрироваться и другие |
| `TRUST_PROXY`    | нет         | `true` за прокси (Render, Caddy, nginx)                             |
| `PORT`           | нет         | порт, по умолчанию 3000                                             |
| `WEB_DIST_DIR`   | нет         | папка собранного интерфейса (в Docker уже задана)                   |

## Важно знать

- Состояние **живой игры** хранится в памяти сервера. Если сервер перезапустится посреди игры, результаты уже сыгранных вопросов сохранятся в журнал, а игру нужно будет начать заново. Домашние задания это не затрагивает.
- Приложение рассчитано на один экземпляр сервера. Для школы или нескольких школ этого с запасом хватит.
