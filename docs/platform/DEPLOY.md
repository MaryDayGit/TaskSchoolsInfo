# Публикация платформы в интернете

> **Опубликовано 29.09.2026:** https://infoklas-school.web.app (кабинет учителя — `/t`, код учителя — как в Клас-пульте). Правила Firestore опубликованы; часть Клас-пульта в них не изменилась (проверено сравнением с действовавшими правилами).

Платформа публикуется автоматически из GitHub (`.github/workflows/deploy-platform.yml`) в Firebase-проект `klas-pult`:

- **сайт платформы — на отдельный адрес**, по умолчанию **https://infoklas-school.web.app**. Это второй сайт того же проекта;
- **правила Firestore** — правила Клас-пульта без изменений плюс правила платформы.

Адрес Клас-пульта **klas-pult.web.app не меняется**: на уроках можно пользоваться Клас-пультом, пока платформа проверяется. Переключение адреса — [этап 7](ROADMAP.md).

Публикация запускается сама после каждого слияния в `main`, если изменились платформа, общий код или правила. Перед публикацией GitHub прогоняет тесты правил, включая все проверки Клас-пульта: правила, которые не проходят тесты, не публикуются.

## Один раз: ключ Firebase для GitHub

1. Откройте https://console.firebase.google.com → проект **klas-pult** → шестерёнка **Project settings** → вкладка **Service accounts**.
2. Нажмите **Generate new private key** → **Generate key**. Скачается файл `.json`.
3. Откройте https://github.com/MaryDayGit/TaskSchoolsInfo → **Settings** → **Secrets and variables** → **Actions**.
4. **New repository secret**:
   - Name: `FIREBASE_SERVICE_ACCOUNT_KLAS_PULT`;
   - Secret: всё содержимое скачанного файла (открыть в Блокноте, выделить всё, скопировать);
   - **Add secret**.
5. Удалите скачанный файл с компьютера: он даёт полный доступ к проекту.

### Другой адрес (необязательно)

Адрес `infoklas-school.web.app` можно заменить. На той же странице откройте вкладку **Variables** → **New repository variable**:

- Name: `FIREBASE_PLATFORM_SITE`;
- Value: имя сайта, например `infoklas-7`. Допустимы латинские буквы, цифры и дефис. Имя должно быть свободно во всём Firebase.

Если имя занято, публикация остановится с ошибкой. Тогда выберите другое имя и запустите публикацию заново.

## Опубликовать

- **Автоматически:** слейте PR в `main`.
- **Вручную:** GitHub → **Actions** → **Deploy platform** → **Run workflow** (ветка `main`).

Через 3–5 минут в конце задачи появится строка «Опубліковано: https://….web.app».

## После публикации

- **Кабинет учителя:** `https://<адрес>/t`.
  - Код учителя тот же, что в Клас-пульте: у них общая база.
  - Старая закладка `…/admin.html` тоже ведёт в кабинет.
- **Страница ученика:** `https://<адрес>/`.
  - На школьных ПК её нужно открыть один раз и ввести номер ПК.
  - Пока идёт проверка, на ПК может быть открыт и Клас-пульт.
- **Данные:** тесты и история Клас-пульта, а также классы старого ІнфоКласа (Render) в платформу пока **не перенесены** — это этап 6. Классы, учеников и тесты в платформе нужно создать заново (тесты можно импортировать текстом).

## Вручную с компьютера

Если ключ Firebase лежит у вас в файле (не в GitHub):

```
npm ci
npm run test:rules
npm run build -w @infoklas/platform
set GOOGLE_APPLICATION_CREDENTIALS=C:\путь\к\ключу.json      (Windows; в Linux/macOS — export …)
node tools/deploy-rules.mjs
npx firebase-tools@15.32.0 --project klas-pult target:apply hosting platform infoklas-school
npx firebase-tools@15.32.0 --project klas-pult deploy --only hosting:platform
```

Правила публикуются скриптом `tools/deploy-rules.mjs` через Firebase Rules API: `firebase deploy --only firestore:rules` сначала проверяет, включён ли Firestore API, а у ключа Admin SDK на эту проверку нет прав (ошибка 403 «Permission denied to get service»).

## Важно: Клас-пульт больше не публикует правила

У проекта один набор правил на всю базу. Команда `firebase deploy` в папке Клас-пульта опубликовала бы его старые правила, и платформа перестала бы сохранять данные. Поэтому для Клас-пульта с этого момента:

```
firebase deploy --only hosting
```

Если это всё же случилось, запустите **Actions → Deploy platform → Run workflow**: правила платформы опубликуются заново.

## Если что-то не работает

| Что видно                                                  | Что сделать                                                                                                                                                                         |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| В Actions: «публікацію пропущено»                          | Не задан секрет `FIREBASE_SERVICE_ACCOUNT_KLAS_PULT` (раздел выше)                                                                                                                  |
| В Actions ошибка у `hosting:sites:create`                  | Имя сайта занято: задайте `FIREBASE_PLATFORM_SITE`                                                                                                                                  |
| На сайте «Немає доступу» / `permission-denied`             | Правила не опубликованы или их перезаписал Клас-пульт. Запустите **Deploy platform** вручную                                                                                        |
| Страница не входит («Не вдалося увійти», ошибки ключа API) | В Google Cloud Console → **APIs & Services** → **Credentials** у ключа «Browser key» могут стоять ограничения по адресам сайтов. Добавьте `https://<адрес>/*` к разрешённым адресам |
| Близко к дневным лимитам (50 000 чтений, 20 000 записей)   | См. [ARCHITECTURE.md](ARCHITECTURE.md#лимиты-тарифа-spark): урок на 30 ПК — около 1 700 записей                                                                                     |
