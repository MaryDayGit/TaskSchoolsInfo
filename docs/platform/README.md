## 1. Два проекта сегодня

|            | **Клас-пульт**                                                                           | **ІнфоКлас**                                                                    |
| ---------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Назначение | управление экранами в компьютерном классе **во время урока**                             | тесты, **домашние задания**, журнал, живые игры                                 |
| Ученик     | ПК с номером, имя вводит сам, без пароля                                                 | класс по коду, выбирает имя, пароль из картинок или слово                       |
| Учитель    | код учителя, без регистрации                                                             | email и пароль                                                                  |
| Главное    | ссылка / сообщение / тест на экраны, блокировка, таймер, руки, история тестов по классам | классы и списки учеников, редактор тестов, задания со сроком, журнал, Classroom |
| Технологии | чистый JS (ES2017), Firebase: Hosting + Firestore + анонимный вход                       | React + TypeScript, свой сервер (Fastify) + PostgreSQL                          |
| Хостинг    | Firebase, **всегда доступен**, бесплатно                                                 | Render + Neon, бесплатный сервер «засыпает» (нужен мониторинг)                  |
| Браузеры   | **Chrome 109 / Firefox 115 на Windows 7** (школьные ПК)                                  | современные браузеры                                                            |
| Тесты кода | правила Firestore, сценарии в Chromium 109                                               | API на PGlite, WebSocket-сценарии                                               |

Проекты дополняют друг друга, но сейчас это два сайта, два входа и два набора тестов. Класс, который писал тест через Клас-пульт, не попадает в журнал ІнфоКласа, а у ІнфоКласа нет управления экранами на уроке.

## 2. Цель

**Один сайт, один вход для учителя, один журнал.** Ученик на уроке и дома пользуется одной и той же страницей.

Требования, которые определяют решения:

1. **Всегда доступен и бесплатен**: без засыпающего сервера и без ежемесячной оплаты.
2. **Работает на школьных ПК**: Chrome 109 и Firefox 115 на Windows 7, слабое железо, эмодзи не отображаются.
3. **Без регистрации** для учеников и без почты для учителя, как в Клас-пульте.
4. **Ничего не теряется**: всё, что сейчас умеют оба проекта, остаётся, и данные Клас-пульта (тесты, история) переносятся.
5. **Качество**: TypeScript, автотесты правил и сценариев, проверка в Chromium 109, CI.

### Главные изменения для пользователей

- **Ученик на уроке** входит так же, как дома: код класса → своё имя → картинки или пароль. Номер ПК страница запоминает сама, как сейчас. Результаты тестов с урока попадают **в журнал конкретного ученика**, а не только «ПК 07 · Оля».
  - Если нужно сделать что-то быстро, без списка класса, остаётся **гостевой вход** как в Клас-пульте (номер ПК и имя): результаты гостей видны на уроке и в истории, но не в журнале.
- **Учитель** входит по **коду учителя** на любом устройстве, как в Клас-пульте. Регистрации и почты нет.
- **«Новий клас»** в Пульте превращается в **выбор класса из списка** («Зараз урок: 5-А»). Ученики видят список имён своего класса, история и журнал разделяются сами.
- **Страница ученика** остаётся по адресу `https://klas-pult.web.app`, поэтому на школьных ПК ничего перенастраивать не нужно.

## 4. Ключевые решения

Подробности и альтернативы в [ARCHITECTURE.md](ARCHITECTURE.md).

| #   | Решение                                                                                                                                                            | Почему                                                                                                                                                                                                                                                                                                                     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Р1  | **Бэкенд на Firebase**, как у Клас-пульта: Hosting + Firestore + анонимный вход. Сервер ІнфоКласа (Fastify, PostgreSQL, Render, Neon) выводится из работы          | всегда доступен, бесплатно (тариф Spark), мгновенные обновления без своего сервера, уже развёрнут и проверен в школе                                                                                                                                                                                                       |
| Р2  | **Интерфейс на React + TypeScript**, как у ІнфоКласа, со **сборкой под Chrome 109 / Firefox 115** (Vite, `build.target`) и обязательными сценариями в Chromium 109 | платформа будет заметно больше обоих проектов (в Клас-пульте один `admin.js` уже 2 300 строк); типы и компоненты нужны, чтобы её можно было развивать. Ограничение «без сборщиков» было нужно, чтобы код гарантированно работал на старых ПК; сборка с целевой версией браузера и тесты в Chromium 109 дают ту же гарантию |
| Р3  | **Правила доступа Firestore вместо сервера**: права, сроки сдачи, попытки проверяются правилами                                                                    | на тарифе Spark нет Cloud Functions; правила уже защищают ответы в Клас-пульте                                                                                                                                                                                                                                             |
| Р4  | **Вход учителя по коду** (механизм Клас-пульта)                                                                                                                    | учитель просил «без регистрации и почты»; механизм уже работает и покрыт тестами                                                                                                                                                                                                                                           |
| Р5  | **Ученик = анонимный вход + «привязка» к ученику класса** по картинкам или паролю, их сверяют правила                                                              | тот же приём, что с кодом учителя: секрет хранится там, где его никто не может прочитать                                                                                                                                                                                                                                   |
| Р6  | **Правильные ответы отдельно** (`keys`), итоговые баллы считает кабинет учителя по «сырым» ответам                                                                 | подход Клас-пульта: ученик не может подсмотреть ответы или подделать балл                                                                                                                                                                                                                                                  |
| Р7  | **Живая игра без сервера**: ведущим выступает браузер учителя, ответы учеников идут через Firestore                                                                | не нужен WebSocket-сервер; задержка 0,5–1,5 с, для викторины этого достаточно                                                                                                                                                                                                                                              |
| Р8  | **Один репозиторий**: этот (`TaskSchoolsInfo`), Firebase-проект `klas-pult`                                                                                        | общий код (`packages/shared`: схемы вопросов, проверка ответов) уже здесь; адрес и данные Клас-пульта сохраняются                                                                                                                                                                                                          |
| Р9  | **Эмодзи на страницах ученика заменяются SVG** (включая картинки-пароли)                                                                                           | на Windows 7 эмодзи показываются квадратиками                                                                                                                                                                                                                                                                              |

## Решения на утверждение

Эти пункты меняют привычное поведение одного из проектов. Перед этапом 1 их должен подтвердить учитель:

1. **Сборка вместо «чистого JS»** (Р2). Отступление от ТЗ Клас-пульта (§2). Взамен каждое изменение проверяется в Chromium 109, а размер страницы ученика ограничен бюджетом (см. [ARCHITECTURE.md](ARCHITECTURE.md#производительность-на-слабых-пк)).
2. **Ученики входят по списку класса**, а не просто вводят имя. Первый вход на уроке займёт на 20–30 секунд больше, зато появится журнал по каждому ученику. Гостевой вход остаётся.
3. **Вход учителя по коду вместо email** (Р4). Сейчас ІнфоКлас использует email. Если позже понадобится автоматическая выгрузка оценок в Google Classroom (Classroom API), придётся добавить вход через Google.
4. **Защита входа учеников слабее, чем на сервере.** Без сервера нельзя заблокировать вход после 5 неверных попыток. Подобрать картинки скриптом технически возможно. Взамен пароль-картинка становится из **4** картинок (20 736 вариантов вместо 1 728), а в журнале видно, когда и с какого устройства ученик входил. Если этого мало: Firebase App Check или тариф Blaze с Cloud Functions (см. [ARCHITECTURE.md](ARCHITECTURE.md#вход-ученика)).
5. **Мгновенный результат домашнего задания.** Сразу после сдачи ученик может прочитать правильные ответы этого задания, чтобы увидеть разбор. Для заданий с несколькими попытками учитель выбирает: «показать разбор сразу» или «только после окончания срока».
6. **Название платформы**: предлагается **ІнфоКлас**, а бывший Клас-пульт становится модулем «Пульт уроку».
7. **Репозиторий `TaskSchoolsInfo` публичный.** Код можно держать открытым: ключи Firebase не секретны, данные защищают правила. Если хотите закрытый, репозиторий можно сделать приватным в настройках GitHub, это ни на что не влияет.
