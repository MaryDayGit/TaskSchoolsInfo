# Полное тестирование платформы

Проверка делится на две части:

- **A. Автоматическая** — на эмуляторе Firebase, её запускает разработчик (или Claude) одной командой. Всё, что можно проверить без настоящих школьных ПК, людей и интернета школы.
- **B. Ручная** — делает учитель на настоящем сайте и настоящих устройствах. Это то, что эмулятор проверить не может: железо и браузеры школы, живые дети, Excel, принтер, проектор, реальная сеть.

Результаты последнего прогона — в разделе [C](#c-результаты-последнего-прогона).

---

## A. Автоматическая проверка (эмулятор)

### Как запустить

```bash
npm ci
node tools/get-chromium109.mjs      # один раз: Chromium 109, как на школьных ПК
npm run test:all                    # всё ниже по порядку, ~5 минут
```

Нужны Node 22 и Java 21 (для эмулятора Firestore). Эмулятор поднимается и останавливается сам, боевая база не затрагивается.

| Команда                  | Что входит                                                      |
| ------------------------ | --------------------------------------------------------------- |
| `npm run check`          | линтеры, форматирование, проверка типов, модульные тесты        |
| `npm run test:rules`     | правила доступа Firestore + прогон переноса данных на эмуляторе |
| `npm run test:e2e`       | сценарии в Chromium 109: учитель, ученики, гости, проектор      |
| `npm run check:platform` | размер страницы ученика ≤ 200 КБ, нет эмодзи                    |

**2. Безопасность данных (правила Firestore, `npm run test:rules`)**

| Кто                         | Что проверено                                                                                                                                                                      |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Посторонний / гость         | не читает классы, списки, пароли, банк тестов, ключи ответов, чужие сдачи, игры                                                                                                    |
| Ученик                      | видит только свой класс; не видит пароли и ответы до разбора; сдаёт только за себя, в срок, попытки по порядку; в игре — один ответ, только на текущий вопрос, до дедлайна + 1,5 с |
| Ученик после «Новий пароль» | старые устройства больше не могут сдавать                                                                                                                                          |
| Учитель                     | всё по коду учителя; поля документов проверяются (лишние поля, неверные значения)                                                                                                  |
| Клас-пульт                  | 19 групп прежних правил Клас-пульта работают без изменений (пока он в ходу)                                                                                                        |
| Перенос                     | копия данных → эмулятор → перенос → сверка количества и баллов по CSV; старые коллекции не меняются; повторный запуск ничего не добавляет                                          |

| 2. Классы и вход     | класс 2–4 и 5–9, дубликаты имён, карточки входа (SVG-картинки), вход 4 картинками, словом, по ссылке `/join`, с телефона, гость по номеру ПК, «Новий пароль» выкидывает устройство                               |
| 3. Домашние          | импорт теста, редактор, задание со ссылкой для Classroom, ученик с телефона (черновик, сдача, разбор), результаты, журнал, CSV с кириллицей, вторая попытка                                                      |
| 4. Урок              | начать урок, вход из списка класса, ссылка только на ПК 03 (≤ 2 с), сообщение, «Я закінчив(ла)», рука, блокировка, тест и CSV, таймер на ПК со сбитыми на 2 часа часами, «Новий клас», **замер записей** за урок |

| Разное               | выход через диалог страницы, старая закладка `/admin.html`, нет горизонтальной прокрутки на телефонах (360, 375, 768, 900 px)                                                                                    |

**5. Бюджет и вид (`npm run check:platform`)**: страница ученика ≤ 200 КБ (слабые ПК, медленный интернет), в интерфейсе нет эмодзи (Windows 7 их не показывает).

**6. Боевой сайт (только чтение, с ключом)**: опубликованные правила совпадают с `firestore/firestore.rules`; сборка сайта открывается с боевой базой без ошибок. Сам адрес `*.web.app` из среды Claude недоступен — поэтому пункт B.1 обязателен.

### Чего автоматика НЕ проверяет

- настоящие школьные ПК с Windows 7, их скорость и шрифты (медленный ПК и интернет только **имитируются**);
- **Firefox 115** и **Safari (iPhone/iPad)**: в среде проверки есть только Chromium, скачать другие браузеры нельзя; встроенные браузеры (Classroom, Viber, Telegram);
- настоящий интернет школы: прокси и фильтры, реальные задержки до серверов Google (эмулятор работает на той же машине, поэтому замеры скорости — нижняя граница);
- как это воспринимают дети (2 класс и картинки, 9 класс и слово);
- Excel/Google Таблицы, принтер, проектор, озвучку вопросов (голоса Windows: в проверке только нажимается кнопка);
- лимиты бесплатного тарифа Firebase на реальной нагрузке (замер есть только на эмуляторе).
